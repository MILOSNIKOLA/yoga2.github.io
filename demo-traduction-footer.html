💡 Comment ça marche ?

Cliquez sur un bouton de langue pour voir le footer se traduire instantanément sans rechargement de page. Chaque élément est identifié par un attribut data-i18n="footer.section.key" qui est résolu dans un objet JavaScript centralisé.

Technologie : 100% JavaScript Vanilla • Zéro bibliothèque externe • Performance optimale
